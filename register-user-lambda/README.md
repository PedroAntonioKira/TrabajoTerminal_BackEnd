# Proyecto: Sistema de interacción con AWS Cognito

Este proyecto contiene un conjunto de funciones implementadas en Go que permiten interactuar con AWS Cognito para gestionar usuarios. Está diseñado para ser modular y fácil de mantener.

## Características principales

- Registrar usuarios en AWS Cognito.
- Validar datos de entrada antes de enviarlos al servicio.
- Construir atributos personalizados para los usuarios.
